# 말끝 통역

말을 마친 뒤 끝에 정해둔 **끝말**(기본: 한국어 "번역", 영어 "translate")을 말하면, 그 앞의 말을 바로 번역해서 읽어주는 통역 웹페이지예요.

구글 번역의 대화 모드는 조용해져야 말이 끝났다고 판단해요. 주변이 시끄러우면 마이크가 계속 소리를 들어서, 말이 끝났는데도 번역을 시작하지 않고 기다려요. 말끝 통역은 조용해질 때까지 기다리지 않고 끝말이 들리는 순간 보내요.

> 구글 번역 앱 자체를 바꾸는 도구는 아니에요. 앱 밖에서 듣기, 번역, 읽어주기를 직접 하는 별도 페이지예요.

## 쓰는 법

1. 아래에서 말할 사람의 언어 버튼을 눌러요. (나 / 상대)
2. 말을 하고 끝에 끝말을 붙여요. 예: "오늘 저녁에 같이 밥 먹을래요 **번역**"
3. 끝말이 들리면 번역문을 크게 보여주고 소리로 읽어준 뒤, 상대가 대답할 차례로 넘어가요. 상대 쪽에는 상대 언어로 "When you finish, say "translate"" 같은 안내가 떠요.

- **지금 번역**: 끝말 없이 지금까지 들은 말을 바로 보내요.
- **지우기**: 지금까지 들은 말을 버리고 다시 들어요.
- **다시 듣기**: 지난 번역을 다시 읽어줘요. 읽는 동안에는 마이크를 쉬어서 읽는 소리를 받아 적지 않아요.

## 설정

| 항목 | 설명 |
|---|---|
| 끝말 | 언어마다 따로 정해요. 쉼표로 여러 개 쓸 수 있어요 (예: `번역, 번역해`). 비우면 "지금 번역" 버튼으로만 보내요. |
| 끝말 확인 시간 | 끝말이 들린 뒤 이만큼(기본 0.6초) 더 들어보고 보내요. "번역가"처럼 끝말로 시작하는 낱말을 잘못 잡지 않으려고 둔 시간이에요. 인식기가 결과를 확정하면 기다리지 않고 바로 보내요. |
| 읽어주기 / 차례 넘기기 / 화면 켜두기 | 끌 수 있어요. |

끝말은 인식기가 잘 알아듣고, 평소 말 끝에 잘 오지 않는 낱말이 좋아요. 영어에서 "over"는 "come over"처럼 문장 끝에 자주 와서 기본값으로 쓰지 않았어요.

## 열기

마이크는 **https 주소**에서만 쓸 수 있어요. 이 폴더가 GitHub Pages에 올라가 있으면 `https://<아이디>.github.io/growlog/interpreter/`로 열면 돼요. PC에서는 로컬 서버로도 열려요.

```bash
python3 -m http.server 5180
```

그다음 http://localhost:5180/interpreter/ 을 열어요.

| 기기 | 브라우저 |
|---|---|
| 안드로이드, PC | Chrome |
| 아이폰 | Safari. 설정에서 Siri와 받아쓰기가 켜져 있어야 해요 |
| Firefox | 음성 인식을 지원하지 않아요 |

## 알아둘 점

- **구글 번역 앱과 동시에 쓸 수 없어요.** 마이크는 한 앱만 쓸 수 있어서, 구글 번역이 듣고 있으면 이 페이지가 마이크를 못 잡아요.
- **음성 인식은 브라우저가 해요.** Chrome은 구글 서버로, Safari는 애플 서버로 소리를 보내 글자로 바꿔요. 그래서 인터넷이 필요하고 오프라인에서는 동작하지 않아요.
- **번역은 차례로 시도해요.** 구글 번역(공식 API가 아닌 무료 주소) → MyMemory(무료, 하루 사용량 제한 있음) → PC Chrome의 기기 안 번역(언어 파일을 이미 받아둔 경우만). 어디서 번역했는지 번역문 아래에 작게 보여줘요. 모두 실패하면 "다시 번역" 버튼이 나와요.
- 무료 구글 주소는 너무 자주 부르면 잠깐 막힐 수 있어요. 그때는 MyMemory로 넘어가요.
- 다른 앱으로 가거나 화면이 꺼지면 브라우저가 마이크를 끊어서 멈춰요. 돌아와서 마이크 버튼을 다시 누르세요.
- 그로우로그 앱과는 따로 동작해요. 인터넷이 꼭 필요한 도구라 그로우로그의 오프라인 저장 목록(`sw.js`)에는 넣지 않았어요.

```
interpreter/app.js       듣기, 끝말 확인, 번역, 읽어주기
interpreter/trigger.js   끝말 찾기와 인식 결과 합치기 (순수 함수)
tests/interpreter.test.js  trigger.js 테스트
```
