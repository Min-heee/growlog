# 그로우로그 🌱

운동·공부·개발·수면·번아웃을 한곳에서 기록하는 자기계발 웹앱의 1차 버전이에요.
빌드 도구나 라이브러리 없이 HTML/CSS/JavaScript만으로 만들었고, 데이터는 브라우저(localStorage)에 저장돼요.

## 실행

ES 모듈을 쓰기 때문에 `index.html`을 더블클릭하면 열리지 않아요. 로컬 서버로 열어주세요.

```bash
python3 -m http.server 5180
```

그다음 브라우저에서 http://localhost:5180 을 열면 돼요.

## 폰에 앱으로 설치하기

그로우로그는 PWA예요. 앱스토어 없이 홈 화면에 설치할 수 있고, 인터넷이 없어도 열려요.

**설치하려면 HTTPS 주소가 필요해요.** 브라우저는 `localhost`와 HTTPS에서만 서비스 워커를 허용해서, 컴퓨터의 `http://192.168.x.x:5180` 주소를 폰으로 열면 설치와 오프라인 실행이 되지 않아요. GitHub Pages, Cloudflare Pages, Netlify 같은 곳에 이 폴더를 그대로 올리면 돼요. 빌드 단계는 없고, 하위 경로(`/growlog/`)에 올려도 동작해요.

- **아이폰**: Safari로 주소를 열고 공유 → 홈 화면에 추가
- **안드로이드**: Chrome으로 주소를 열고 설정 화면의 앱 설치하기, 또는 브라우저 메뉴의 앱 설치

기억해둘 점:

- 기록은 그 기기의 그 앱 안에만 저장돼요. 설정의 내보내기로 백업해두세요.
- 아이폰은 Safari와 설치한 앱의 저장 공간이 따로일 수 있고, Safari에만 둔 기록은 일주일쯤 열지 않으면 지워질 수 있어요. 홈 화면에 추가해서 쓰는 걸 권해요.
- 타이머가 도는 동안 화면이 꺼지지 않게 요청하지만, iOS 18.4 미만의 홈 화면 앱에서는 동작하지 않을 수 있어요. 화면이 꺼지거나 다른 앱으로 가면 앱이 멈춰 알림음이 나지 않아요. 시간은 시작 시각으로 계산하므로, 돌아오면 끝난 세션이 끝난 날짜로 기록돼요.
- 앱은 저장된 파일로 바로 열리고, 뒤에서 새 버전을 확인해요. 코드를 올리면 앱을 연 뒤 몇 초 안에 새 버전을 전부 받아 **새로고침** 안내를 띄워요. 일부만 받다 끊기면 옛 버전을 그대로 써서 파일 버전이 섞이지 않아요.
- 파일을 추가하거나 지웠다면 `sw.js`의 `FILES` 목록도 고쳐주세요. 빠뜨린 파일은 오프라인에서 열리지 않고, 지운 파일이 목록에 남으면 새 버전을 받지 못해요. `node --test tests/`가 이 목록을 검사해요.
- 개발 중에는 같은 이유로 고친 내용이 다음 새로고침에 보여요. 바로 보려면 브라우저 개발자 도구의 Application → Service workers에서 Update on reload를 켜주세요.

## 화면

| 화면 | 하는 일 |
|---|---|
| 오늘 | 컨디션(에너지·스트레스·기분), 수면, 활동 기록, 이번 주 목표 진행률 |
| 타이머 | 25/50분 포모도로와 스톱워치. 끝나면 자동으로 기록되고, 새로고침해도 이어져요 |
| 통계 | 7/30일 활동 시간, 영역별 합계, 수면 시간, 기록 목록 |
| 번아웃 | 0~100 지수, 회복 조언, 요인별 점수, 14일 추이 |
| 설정 | 영역 추가(최대 6개), 주간 목표, 수면 목표, 테마, JSON 백업·복원, 샘플 데이터 |

## 코드 구조

```
index.html          화면 뼈대와 메뉴
css/styles.css      디자인 토큰과 스타일 (라이트/다크)
js/app.js           라우팅, 화면 그리기, 이벤트 위임
js/store.js         데이터 저장과 변경 함수
js/burnout.js       번아웃 지수 계산
js/charts.js        SVG 차트
js/ui.js            토스트, 툴팁, 공용 조각
js/views/*.js       화면별 render(화면 만들기)와 on(이벤트 처리)
js/pwa.js           서비스 워커 등록, 설치 안내
js/backup.js        백업 파일 내보내기
js/sample.js        샘플 데이터
sw.js               오프라인 실행 (저장된 파일로 열고, 새 버전은 통째로 교체)
manifest.webmanifest  앱 이름, 아이콘, 홈 화면 바로가기
icons/              앱 아이콘 (scripts/make_icons.py로 생성)
```

새 화면을 추가하려면 `js/views/`에 파일을 만들고 `js/app.js`의 `views`와 `index.html`의 메뉴에 등록하면 돼요.

## 번아웃 지수 계산

최근 7일 중 3일 이상 컨디션이나 수면을 기록하면 지수를 보여줘요. 기록을 요인별로 0~1 점수로 바꾼 뒤 가중 평균하고, 기록이 없는 요인은 빼고 계산해요.

| 요인 | 비중 | 계산 |
|---|---|---|
| 스트레스 | 25 | 평균 스트레스 |
| 에너지 저하 | 20 | 평균 에너지의 반대 |
| 수면 부족 | 20 | 목표 대비 부족한 시간(2.5시간이면 최대) 70% + 수면의 질 30% |
| 작업량 | 15 | 하루 평균 부하 시간(4시간부터 9시간까지) 65% + 쉬는 날 없음 35% |
| 기분 저하 | 10 | 평균 기분의 반대 |
| 회복 부족 | 10 | 회복 영역의 주간 목표 대비 부족한 정도 |

단계: 안정(0~29), 주의(30~49), 경고(50~69), 위험(70~100).
가중치와 기준은 `js/burnout.js`에서 바꿀 수 있어요. 스스로 돌아보기 위한 참고 지표이고 의학적 진단이 아니에요.
